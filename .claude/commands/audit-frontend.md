Your goal is to audit the codebase for potential security vulnerabilities. You will analyze the code for common security issues such as SQL injection, cross-site scripting (XSS), and insecure authentication practices.

Do the following:
1. Run `docker compose exec frontend npm run lint` to check for any linting issues that may indicate potential security vulnerabilities.
2. Run `docker compose exec frontend npm run test` to execute any existing tests that may cover security-related functionality.
